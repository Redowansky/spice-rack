Troubleshooting

⚠️ App says the extension is Untrusted?

Normal for this store — the extensions are signed with our own key, not a public store key. Tap Trust to install.

⚠️ "Not associated with any store" banner?

That shows on sideloaded APKs. Add the store first (buttons on the extensions page), then install the extension from inside the app — the banner goes away and updates work.

🔧 Add the store manually

Mihon: More → Settings → Browse → Extension repos → paste the Mihon URL.
Aniyomi: More → Settings → Browse → Anime extension repos → paste the Aniyomi URL.

⚠️ Extension list says my app is outdated

Update Mihon / Aniyomi itself from its official release first — store indexes need a recent app version to load.
