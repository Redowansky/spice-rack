Adding the extension store

Before you start

You need Mihon 0.21.3 or newer, or a recent Aniyomi, on an Android device. The store buttons below only work on Android with the app installed.

Add store to Mihon Add store to Aniyomi

Adding the store manually

Mihon: More → Settings → Browse → Extension repos → paste the Mihon URL.
Aniyomi: More → Settings → Browse → Anime extension repos → paste the Aniyomi URL.

https://raw.githubusercontent.com/Redowansky/spice-rack/repo/index.pb
https://raw.githubusercontent.com/Redowansky/spice-rack/repo/aniyomi/index.min.json

Reinstall the extensions

If an extension misbehaves after a store change, remove it in the app and install it again from the store list inside the app — not from a sideloaded APK.

Troubleshooting

⚠️ App says the extension is Untrusted?

Normal for this store — the extensions are signed with our own key, not a public store key. Tap Trust to install.

⚠️ "Not associated with any store" banner?

That shows on sideloaded APKs. Add the store first (buttons above), then install the extension from inside the app — the banner goes away and updates work.

⚠️ Extension list says my app is outdated

If you are seeing an empty extension list with the message "Outdated app", your app is no longer compatible with this store's extensions. Make sure your app is updated to the latest version! This store supports Mihon and Aniyomi.
